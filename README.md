# Alberto Ancona

Personal portfolio: enterprise AI and data product leadership, agentic workflows, governance, and selected work.

Website: https://albertoancona.com/

This repository contains the production portfolio. GitHub Pages publishes the root of `main`. The site is a self-contained HTML application; no build step or external runtime service is required.

## Published files

- `index.html`: portfolio, including its application, fonts, and artwork.
- `og-image.png`: social sharing preview.
- `.nojekyll`: serve the static site directly.
- `robots.txt` and `sitemap.xml`: discovery metadata.

The local version comparison and career assessment are not included in this deployment.
